## 페이지별 심의필

STABLELIFE 연금보험 비교 서비스. 심의 주체는 (주)영진에셋 준법감시인입니다. 페이지 이름은 서비스의 표기 기준에 따라 회사명, 상품명 없이 적었습니다.

블로그 글도 건별로 심의를 받습니다. 예를 들어 [AI 검증 에이전트](review-agent.md)를 거쳐 만든 단기납 연금보험 해설 글은 심의필 제2026-590호를 받고 2026. 10. 06 발행했습니다.

## 근거 기록 원칙

페이지마다 유의사항 파일 머리에 심의번호와 유효기간을 두고, 바로 아래에 근거 문서와 판단 이유를 남깁니다. 하단 표기는 이 값을 읽어 자동으로 만들어집니다.

**기록 예시** (단기납 연금보험 B, 원문을 공개용으로 줄임)

```
reviewNumber: 제2026-591호
validFrom:    2026.10.06
validTo:      2027.10.05

- 영진에셋 준법감시인 심의필 제2026-591호로 확정 (2026.10.06 승인)
- 보험사 원본 자료에 찍힌 준법감시인 번호(안내장, 전단, 가입제안서 각 1건)는
  각 원본 문서 그대로의 내용에만 대응하므로 이 페이지의 심의번호로 쓰지 않음
- 공시이율 연동형이라 "금리연동형 상품에 대한 안내" 블록 포함,
  이 상품의 핵심 기능인 "최저계약자적립액 보증에 대한 안내" 블록 추가
- 원본: 상품안내장 p.3, 5, 8
```

**가입제안서를 쓰지 않는 이유** (단기납 연금보험 A 기록 중)

> 가입제안서에 찍힌 심의번호는 원문에 "본 상품설명서는 보험설계사의 참고용으로 출력된 것이며 고객전달 및 청약목적으로 사용하실 수 없습니다"라고 명시되어 있어 쓰지 않았습니다.

## 재심의 판단 기록

### 재심의 사례: 단기납 연금보험 A

| 시점 | 상태 |
|---|---|
| 처음 게시 | 상품안내장 원문만 옮긴 상태. 안내장의 심의번호가 페이지 내용과 일치 |
| 2026. 08. 02 | 안내장에 없는 문장 2개(환급 조건, 비과세 요건) 추가. "본 광고는 심의기준을 준수하였으며" 문구가 새 문장까지 보증하는 것처럼 보이면 안 되므로 기존 번호를 내리고 칸을 비운 뒤 재심의 신청 |
| 2026. 08. 20 | 계산기를 연금액 계산에서 해약환급금 계산으로 바꾼 개편까지 같은 재심의에 포함. 승인, 제2026-582호 |

기존 번호를 다시 쓰지 않은 이유: 원본 안내장 번호는 "원본 문서 그대로의 내용"에만 대응합니다. 내용이 바뀐 이상 그 번호로는 이 페이지를 대표할 수 없습니다.

### 변경 시 판단

| 날짜 | 변경 내용 | 판단 |
|---|---|---|
| 2026. 08. 02 | 단기납 연금보험 A에 안내장 밖 문장 추가 | 번호 내리고 재심의 신청 |
| 2026. 08. 20 | 같은 페이지 계산기 성격 변경 | 진행 중인 재심의에 포함 |
| 2026. 08. 20 | 상품 설명과 유의사항 원문 | 재심의 범위를 넓히지 않도록 원문 순서와 문구 유지 |
| 2026. 10. 06 | 상품 7개 계산 화면 구성 변경 (로그인 후 결과 공개) | 재심의 필요 여부 확인 대상으로 기록 |
| 2026. 10. 14 | 결과 화면 안내 문구 교체, 위치 이동 | 재심의 불필요로 판단 |
