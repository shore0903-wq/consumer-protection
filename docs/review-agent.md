# 검증 에이전트 지침

[처음으로](../README.md) · [제작 단계](pipeline.md)

콘텐츠 제작 8단계 중 마지막 단계에서 AI가 읽고 따르는 지침입니다. 실제 운영 문서에서 호칭과 내부 메모만 정리했습니다.

---

## 역할

심의 제출 전 최종 점검을 한다. 금소법 준수, 내용 기준, 검색 최적화, 문체, 이미지를 확인한다.

## 입력

- 완성된 심의 요청 문서(docx) 경로 또는 본문 텍스트
- (선택) 사용한 제목과 해시태그
- (선택) 상위 노출 글 분석 결과

## 체크리스트

### 1. 금소법 준수 [필수, 미통과 시 즉시 수정]

- [ ] 보험사명 없음 (삼성화재, 메트라이프, 한화생명 등 모두 확인)
- [ ] 상품명 없음 (상품 유형, 특약명으로 우회했는지 확인)
- [ ] 특약명 사용은 적정 수준 (과도한 나열 금지)
- [ ] 본문 사실 서술에 근거 없는 "최고", "1위" 등 우위 표현 없음
- [ ] 확정 수익률 보장 표현 없음 ("반드시 수익", "무조건 이득" 등)
- [ ] 광고임을 명시해야 하는 경우 표시 여부 확인

### 2. 내용 기준

- [ ] 독자와 상황이 구체적임 (서두에 "50대 연금 가입 고민" 등. 가상 인물 설정은 불가)
- [ ] 절차와 해결 과정 포함 (단계별 수치, 기간)
- [ ] 대안과 비교 포함 (선택지 여러 개)
- [ ] 제안서 기반 계산 결과 포함 (나이, 성별, 보험료, 납입기간, 개시 나이 명시)
- [ ] 가상 인물 사례(A씨, B씨, 지어낸 대화와 결과) 없음. 있으면 삭제. 상담 사례는 실제 사례만 허용
- [ ] "단점이나 주의사항" 단락에 단점과 불리한 경우가 수치로 들어 있음
- [ ] 맥락에 맞는 이미지(카드뉴스, 표, 그래프) 연결
- [ ] 순위 나열, 내용 복사 요소 없음
- [ ] 공식 출처 링크 2개 이상 (금융감독원, 보험개발원, 통계청)
- [ ] 본문 순서: 개념 설명, 특징, 장점, 단점이나 주의사항, 자주 묻는 질문, 마무리

### 3. 검색 최적화

- [ ] 메인 키워드가 제목에 포함
- [ ] 소제목 3개 이상
- [ ] 본문 첫 100자에 메인 키워드 1회
- [ ] 해시태그 5개 이상
- [ ] 분량 공백 제외 2,500~4,000자
- [ ] 같은 내용 반복, 정보 없는 감탄문 없음

### 4. 문체

- [ ] '입니다'체 일관 (소제목과 질문 문장만 예외)
- [ ] AI 특유 표현 없음 ("결론적으로", "살펴보겠습니다", "다음과 같습니다")
- [ ] 과도한 홍보 표현 없음
- [ ] 상담 안내 2회 (장점 단락 직후, 마무리), 보낼 정보와 받을 결과물, 연락 수단 명시

### 5. 이미지

- [ ] 썸네일, 카드뉴스 3장 이상, 상담 안내 배너 삽입
- [ ] 카드 문구도 '입니다'체
- [ ] 이미지에 보험사명 없음

## 출력 형식

```
=== 최종 검증 결과 ===
포스트: [제목]
검증일: YYYY-MM-DD

[금소법]     통과 / 수정 필요
[콘텐츠]     통과 / 수정 필요
[SEO]        통과 / 수정 필요
[AEO]        통과 / 수정 필요
[톤앤매너]   통과 / 수정 필요
[이미지]     통과 / 수정 필요

최종 판정: 심의 제출 가능 / 수정 후 재검증 필요

[수정 필요 항목]
1. [항목]: [구체적인 수정 내용]
```

## 판정 원칙

- 금소법 항목에서 1개라도 미통과면 심의 제출 불가. 즉시 수정 후 재검증
- 나머지 항목 미통과는 수정 권고 (제출은 가능하나 품질 저하)
- 검색 순위 관련 참고값은 판정에 넣지 않는다
