# 콘텐츠 제작 단계

[처음으로](../README.md) · [검증 에이전트](review-agent.md)

보험 정보 블로그 글을 만드는 8단계입니다. 단계마다 기준 문서를 두고 AI(Claude Code)가 그 문서를 읽고 작업합니다. 금소법 관련 점검은 마지막 검증 단계에만 몰아두지 않고, 앞 단계에서부터 걸러지게 나눠 넣었습니다.

| 단계 | 하는 일 | 금소법 관련 기준 | 사람 승인 |
|---|---|---|---|
| 1. 자료 조사 | 상품 자료와 공식 통계 정리 | 수치는 고객 배포용 자료에서만 가져옴 | |
| 2. 키워드 분석 | 검색량 기준 메인 키워드 후보 2~3개 | 보험사명이 들어간 키워드는 후보에서 제외 | |
| 3. 상위 글 분석 | 후보별 상위 노출 글 수집, 비교 | 상위 글에 있어도 보험사명, 상품명, 가상 인물 사례는 따라 쓰지 않음 | **메인 키워드 확정** |
| 4. 검색 설계 | 제목, 소제목, 질문 구성 | | |
| 5. 본문 작성 | 제안서와 캡처 기준으로 작성 | 아래 "본문 작성 기준" | **본문 검토** |
| 6. 카드뉴스 | 썸네일, 본문 카드, 상담 안내, 법적 고지 카드 | 법적 고지 문구는 표준 원문 고정 | **카드 검토** |
| 7. 문서 생성 | 본문과 이미지를 심의 요청 문서(docx)로 묶음 | | |
| 8. 검증 | [검증 에이전트](review-agent.md) 판정 | 금소법 항목 하나라도 걸리면 제출 불가 | |

검증을 통과하면 대리점 준법감시인 심의에 제출하고, 심의필을 받은 뒤 심의번호를 넣어 발행합니다.

## 본문 작성 기준 (금소법 관련 발췌)

- 보험사명 완전 제외 (회사명 언급 시 심의 반려)
- 상품명 제외. 상품 유형이나 특약명으로 설명
- 본문은 정보 제공 어조. 비교 제안은 상담 안내 단락에서만
- 확인되지 않은 사실은 쓰지 않음 ("모든 회사" 금지, 확인 전에는 "여러 회사")
- 경험은 실제로 있는 것만 씀
  1. 제안서 직접 계산: 수치는 제공된 제안서에서 가져오고 나이, 성별, 납입기간, 개시 나이를 명시
  2. 실제 상담 사례: 받은 내용 이상으로 각색하지 않음
  3. 확인 가능한 출처가 있는 화제와 질문
- 실제 사례가 없으면 사례 단락 자체를 만들지 않음
- 본문 순서에 "단점이나 주의사항" 단락을 반드시 둠

## 법적 고지 카드 표준 원문

글마다 마지막 카드에 넣는 문구입니다. 글 주제에 맞춰 고치지 않고, 디자인을 바꿀 때는 이전 문구와 글자 단위로 같은지 대조합니다 (2026. 10. 14 디자인 교체 때 282자 일치 확인).

> 보험계약자가 기존 보험계약을 해지하고 새로운 보험계약을 체결하는 과정에서
> 1. 질병이력, 연령증가 등으로 가입 가능한 담보와 가입금액, 보험료는 달라질 수 있습니다.
> 2. 가입 상품에 따라 새로운 면책기간 적용 및 보장 제한 등 기타 불이익이 발생할 수 있습니다.
> 3. 내부 심사기준에 따라 가입이 거절될 수 있습니다.
>
> 상기 내용은 모집 종사자 개인의 의견이며, 계약 체결에 따른 이익 또는 손실은 보험 계약자 등에게 귀속됩니다. 본 광고는 광고심의기준을 준수하였으며, 유효기간은 심의일로부터 1년입니다.

심의필 번호와 유효기간은 카드 이미지에 넣지 않고, 심의를 받은 뒤 본문에 직접 넣습니다. 번호가 바뀔 때마다 이미지를 다시 만들다 생기는 실수를 없애기 위해서입니다.
